NCM and CEST from the barcode

Companion of Product SI5 GTIN lookup for the OCA Brazilian fiscal engine (l10n_br_fiscal). Installed automatically when both are present.

Exact matches only

An NCM or CEST is offered only when the exact code exists in l10n_br_fiscal.ncm / l10n_br_fiscal.cest. No guessing.

CEST follows the NCM

The CEST is suggested only when it belongs to the NCM the product will have, the same rule as the fiscal engine.

You confirm

One checkbox each, never pre-selected, plus confirmation because NCM/CEST live on the product template.
