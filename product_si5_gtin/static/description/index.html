Step 1

Start from the barcode

Create the product with its barcode, or open an existing one, and click the button. The lookup only runs when you ask: never on import, onchange or in bulk.

Step 2

Review picture and fiscal codes

The picture is downloaded only after you confirm, validated (format, size, dimensions) and previewed. The bytes you saw are the bytes applied.

NCM and CEST are offered only on exact matches in the fiscal tables, and the CEST only when it belongs to the NCM. Changes to shared data need an extra confirmation.

Step 3

Product ready to sell

Name, picture, weight, internal note with brand and category, NCM and CEST, in seconds. WebP pictures are converted so Odoo thumbnails and PDF reports work.

Features

  • Name, internal note (brand, category, source), gross weight, picture
  • NCM / CEST for l10n_br_fiscal (companion module)
  • Template picture for single-variant products; variant picture otherwise
  • Restricted-circulation prefixes rejected; check digit validated
  • One token per company, visible to administrators only
  • Hardened client: fixed hosts, TLS, size limits, no secrets in logs
  • English and Brazilian Portuguese

Set up in 3 steps

  1. Create a free account at global.si5.com.br
  2. Create an API token in Minha conta
  3. Paste it in Settings › General Settings › SI5 Global
