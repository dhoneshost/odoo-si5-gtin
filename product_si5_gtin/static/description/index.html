Fill products from the barcode

Look up a GTIN on SI5 Global, a catalogue of Brazilian retail products, and get suggestions for name, picture and weight, plus NCM / CEST references. Nothing is written until you review and select each field.

1

One click

Button Look up GTIN with SI5 on the product form. Works with EAN-8, EAN-13, UPC-A and GTIN-14.

2

You decide

Current × suggested, side by side. Nothing comes pre-selected: tick only what you want to replace.

3

NCM / CEST suggestions

With OCA l10n_br_fiscal, the review can also suggest matching NCM and CEST records. Other fiscal settings stay with you and your accountant.

Step 1

Start from the barcode

Create the product with its barcode, or open an existing one, and click the button. The lookup only runs when you ask: never on import, onchange or in bulk.

Step 2

Review picture and fiscal codes

The picture is downloaded only after you confirm, validated (format, size, dimensions) and previewed. The bytes you saw are the bytes applied.

NCM and CEST are offered only on exact matches in the fiscal tables, and the CEST only when it belongs to the NCM. Changes to shared data need an extra confirmation.

Step 3

Only the selected fields are saved

The fields you ticked are written to the product; everything else stays as it was. WebP pictures are converted so Odoo thumbnails and PDF reports work. Prices, taxes, fiscal type and other settings are not changed.

What this module fills

Always as a suggestion, only when the field is ticked.

  • Product name
  • Internal note with brand, category and source
  • Gross weight (converted to the database weight unit)
  • Picture (template picture for single-variant products, variant picture otherwise)
  • NCM and CEST records, only with l10n_br_fiscal and the companion module

It does not set prices, taxes, fiscal type, ICMS origin, tax rates, stock or accounting data.

SI5 Global account and plans

An SI5 Global API token is required (one per company).

  • Free plan: daily lookup quota, enough to use every feature of this module
  • Paid plans: higher quota
  • Paid plans also include, in the SI5 API, a fiscal sheet (IBPT, IPI, PIS/COFINS, ST, IBS/CBS by state). This module does not read or apply that data.

Account, token and plans are managed at global.si5.com.br.

What is sent to the SI5 Global API

  • Lookup: one HTTPS request from the Odoo server with the barcode (GTIN) of the product, the company token and a User-Agent naming this module.
  • Picture: only after you click Confirm download, one HTTPS request to the SI5 picture server, without the token.
  • Requests run only when a user clicks the button. Nothing runs in the background.
  • Not sent: product name, prices, stock, customers, partners, invoices, users or any other Odoo data.
  • The token is stored on the company (administrators only) or in the server environment, and is never shown in the browser, exports or error messages.
  • Like any API, SI5 Global receives the request itself (barcode, time and the Odoo server IP) to count the quota.

Set up

  1. Create an SI5 Global account and an API token (in Minha conta at global.si5.com.br).
  2. In Odoo: Settings › General Settings › SI5 Global, paste the token for the current company.
  3. Optional: install l10n_br_fiscal to receive NCM / CEST suggestions.

🇧🇷 Em português

Consulte o produto pelo código de barras no SI5 Global e receba sugestões de nome, foto e peso, além de referências de NCM e CEST. Nada é gravado sem a sua revisão: você marca campo a campo. Com a localização brasileira da OCA (l10n_br_fiscal), o módulo complementar sugere os registros de NCM e CEST das tabelas fiscais. Demais configurações fiscais (tipo fiscal, origem, tributos) continuam com você e seu contador.

À API vão apenas o código de barras, o token da empresa e a identificação do módulo; a foto só é baixada depois da sua confirmação. Nenhum outro dado do Odoo é enviado. Crie a conta e o token em global.si5.com.br (Minha conta) e cole em Configurações › SI5 Global.
