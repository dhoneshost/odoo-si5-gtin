1. Open a product (or the specific variant) with a barcode and click
   **Look up GTIN with SI5**.
2. Compare current and suggested values. Tick only the fields to replace.
3. For the image, click **Confirm download and preview image**, check it, then
   tick **Replace image**.
4. Name and description belong to the product template: tick the confirmation
   about shared data, then **Apply selected fields**.

If the product changes after the lookup, run it again. A review can be applied
once. Restricted circulation codes (prefixes 2xx, 040–049) are rejected.
